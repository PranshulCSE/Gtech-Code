# 🚀 GTech Code | MERN Stack Coding Platform

GTech Code is a comprehensive, full-stack web application designed for developers to hone their coding skills, take challenges, participate in contests, and manage technical submissions. Built on the powerful **MERN Stack**, it features a secure, scalable backend and an intuitive frontend experience for seamless code practice which i am going to implement in Geeta technical hub at Geeta University..

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS (or bootstrap, edit as needed), Redux Toolkit (for state management)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB with Mongoose ODM
* **Authentication:** JSON Web Tokens (JWT) & Bcrypt

---

## ✨ Key Features

* **User Authentication:** Secure signup, login, and profile management.
* **Coding Challenges:** Browse and sort technical problems based on difficulty and patterns.
* **Code Submissions:** Manage project or code submissions seamlessly through a dedicated user dashboard.
* **Real-time Analytics:** Track solved problems, performance metrics, and activity progress.
* **Responsive UI:** Optimized for a smooth experience across both mobile and desktop screens.
